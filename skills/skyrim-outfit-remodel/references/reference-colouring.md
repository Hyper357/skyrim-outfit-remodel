# 按艺术参考精准分区上色

目标是把参考中的材料、分区和层次转成该网格真实 UV 上的蒙版。单张渲染图没有足够信息直接还原 albedo/roughness，也不能保证背面设计；先记录可观察部分与设计推断。

## 先认部件，再画蒙版

1. 核对实际 NIF shape、原 UV、使用的纹理、共享 shader/TXST 和 MO2 winner。用彩色 shape ID、连通组件 ID 或单部件隔离渲染定位。图上像管道的线可能实际在另一块网格中，不能只凭 shape 名猜。
2. 将参考拆成“琥珀主体、黑色软层、银色内衬、黄铜硬件”等材料角色，定义前/侧/后边界、包边、高领、高叉、管道。几何轮廓、颜色和物理材质分开记录。
3. 生成蒙版优先级：明确 face/组件集合 > 网格空间区域烘焙到 UV > 局部手绘 UV mask > 仅凭旧图 RGB 阈值。RGB 阈值适合初筛，阴影/高光/共享图集会污染结果。

## 从网格空间转到 UV

在每个 UV 三角面内 rasterize 重心坐标，用同一系数插值得到该像素的三维位置、组件或区域属性。这样“高叉”“银色到锁骨”能按实际身体空间定义，再落到 UV：

```text
P(pixel) = u*P0 + v*P1 + w*P2
mask(pixel) = region_rule(P(pixel), face_role)
```

高叉可由经过批准的 V 形边界曲线决定，再检查整个内腿，而不是只替换原图红色。案例的坐标、斜率和阈值不适用于另一件衣服。物体轴向、NIF local/world 变换先明确；UV 的 V 方向用编号棋盘格实测，别默认翻转。

UV 重叠时，一个像素可能对应多个区域，三维规则结果不能直接“最后写入覆盖”。先检测冲突；按设计拆成私有图集/材料，或明确共享规则。蒙版边缘适量 padding，覆盖 mip 和 UV 岛边缘；不能跨相邻岛无限膨胀。按材质分离 shape 或给私有匹配路径时，不修改无关装备的共享图。

## 材质和细节

- 从**实际目标黄铜部件**比较 albedo、roughness、metallic 与 normal。别把参考渲染中白色高光当作底色；也别只整体乘亮度。
- 银色乳胶需要柔性起伏、清晰反射和涂层，反射依赖 normal/roughness/金属颜料选择与光照。单纯漫反射刷白不会得到银色，纯镜面金属常数也不是唯一配方。
- 保留原法线中自然、不规则的张力和关节褶皱。跨衣物复用细节需按片区转移或高低模烘焙，不能把另一套 UV 的 normal 整张覆盖；重新核对切线方向、绿通道、法线强度。别增加整齐等间距的全身条纹。
- 去文字需要一起处理 albedo、normal/height、发光及 roughness 中的残留。局部 AI 纹样只作为候选补丁合成到明确 mask 内；保留 UV 岛、边缘、其余像素与来源记录。不能让模型重新想象整张 UV 图。
- 反射风格通过材质和照明实现，不把摄影棚亮条直接画进 albedo。

## 复核颜色

先用中性光和固定曝光核对区域；再分别检查正/侧/后及关节近景。导出 DDS 后读取实际 DDS 重新渲染，并逐通道对照源图：sRGB 输入 PNG 只指定 sRGB 输出格式可能发生额外 gamma 转换，导致黄铜发白。TruePBR 的编码、通道与工具见 [PBR 材质参考](../../skyrim-truepbr-workflow/references/materials.md)。Blender 和 BodySlide 预览均不等同于游戏光照。
