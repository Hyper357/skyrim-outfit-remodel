# 故障定位表

| 现象 | 第一轮检查 | 定向处理和回归 |
|---|---|---|
| Add Project/归零后过粗，preset 后正确 | raw source、实际 slider 值、隐藏非零默认修正、匹配 reference | 按 base-shape.md 只处理已确认的固定修正，比较前后 preset 两端及新的裸零位；不把个人 preset 整体设 base |
| 高光锯齿/色块 | 中性材质是否也出现；几何曲率、重复面、split normals、UV、normal/mask | 逐层隔离；修几何不先盲降反射；源与构建输出同角度对照 |
| UV 接缝破裂 | 原 UV 层、镜像/填充、拆点法线、DDS mip | 保留有意 UV 拆点；检查缩小贴图和导出切线，不合并所有重复坐标点 |
| 转头衣领不动 | 领口实际骨列表/权重、绑定和参考姿态 | 局部增加正确颈部渐变，低/仰头再测；收紧几何不能替代权重 |
| 指头/两腿互相拉扯 | 近邻供体误投、搜索范围、左右骨名 | 区域隔离后重转移，测试单指/单腿 |
| slider 爆点/模型炸开 | 顶点顺序/拆点、shape 名、OSD/TRIP 数据集和 base | 重建最终索引映射/形态，不仅检查点数或索引范围 |
| BS 正常、游戏体型不变 | BODYTRI 路径、TRIP shape、运行时形态系统、实际 winner | 检查完整引用链；重建和重载目标资源 |
| BS 重建恢复旧模型 | 实际加载 OSP/ShapeData、输出目录和 winner | 更新正确源工程，用新隔离目录再次构建 |
| 穿戴不可见/孔洞 | ARMA 路径/性别/种族、插槽/分区、权重、面向、body 遮挡 | 对照已知正常装备；不要只靠 double-sided 或删身体掩盖 |
| 一穿戴/物品预览 CTD | 最新 CrashLogger 时间、重复 shape/模型名、穿戴与 GO 资源、shader/skin 结构 | 精确定位触发文件，最小修复，独立解析+预览；日志栈中出现渲染插件不等于根因 |
| 物理抖动/塌陷 | 原物理骨链、XML/collision 名、复制权重是否覆盖 | 回归原配置，按 physics.md；停止随机参数连试 |
| BS 启动 0x5 | MO2 启动方式、VFS 注入/路径、当前进程和日志 | 先正常重启并核验环境，单次恢复不证明杀软或 DLL 是根因 |

每个问题记录本轮改了什么、哪个对照排除了什么、哪项仍未做。不要用早于本轮修改的日志证明本轮失败，也不要用另一个模型的预览通过代替触发模型验收。
