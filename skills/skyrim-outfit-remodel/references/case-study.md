# J3 高跟靴案例与边界

本流程来自一轮现有 NIF 毛坯的多次重塑和回游戏适配。用户后来明确认可高跟靴重塑效果；这不代表每个修订版本、动作或整套装备均有完整游戏验收。

有效方法：先统一多视角参考；先鞋身/底边再薄底/跟座；圆润后跟与酒杯口收束；确认前掌后保护该区域；浅细错落褶皱集中膝踝；整理密度与过渡；保留原穿戴姿态并按配套胶衣同 preset 贴合。

真实记录覆盖：可编辑四边工程、游戏三角输出、BodySlide source/OSP/OSD/TRIP、两端静态间隙与实际构建；局部膝褶皱修改保持其他区域不变。高反射放大曲率不连续，修复后需要补回被平滑抹掉的少量褶皱。造型认可、数值校验和游戏动作验收应分开。

附带经验：同套材质需比较目标区域纹理与遮罩，不只 shader 参数；一次本地工具零改动重存出现蒙皮索引变化，因此该环境采用不改非目标结构的修复并独立读取。这个观察不构成“所有 PyNifly 版本都有问题”的结论；后续 agent 应对自己版本做往返实验。

其他部位的状态：手套已有材质/资源和 CTD 调查经验；领口“转头不跟随”列为颈部权重/绑定检查案例，尚未在本轮独立完成根因验证或修复验收；硬甲、头套、SMP 需要各自真实案例再提升验证等级。这里没有提供任何原模组资产。
