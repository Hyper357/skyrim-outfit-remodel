# 裙摆、披风及物理骨链

此分支是调查和保全流程，尚无本仓库完整 remodel 游戏验收案例。适用于现有 SMP/自定义骨链装备；不能据此宣称自动完成物理移植。

1. 枚举 shape、所有人体/物理骨、骨层级/绑定矩阵、物理 XML、NIF extra data 引用、碰撞体/名称、材质和当前可运行行为。保存原件。
2. 把固定接合区、模拟区和碰撞层分开，确认新网格是否只改变外观还是改变模拟拓扑/质量分布。
3. 保留原运动层作权重供体。复制人体权重时保护物理骨，不能对全件 Clear Weights 再用裸身 Copy Bone Weights。
4. 仅坐标微调也查碰撞层和附着边；重拓扑后重新评估受模拟顶点、骨链、碰撞名称与 XML 引用。骨名改动需同步所有引用。
5. 调研实际物理插件版本、作者配置说明和已知工作装备的结构。社区经验只提供实验方向；不套用另一身体/游戏分支的参数。
6. 隔离测试静止、行走、急转、蹲伏、传送/重新装备及恢复，观察发散、持续抖动、塌陷和穿插。先回归原模型/配置定位变化，不反复随机调质量/阻尼。

若无法解释骨链或配置与新网格的关系，停止相关物理写入；可继续 UV、静态造型等独立工作，交接时写明缺少的工具/资料/测试。物理通过前不把整件标记完成。
