# UV、法线与烘焙

## UV 路线

| 情况 | 方法 | 必查 |
|---|---|---|
| 索引不变、原贴图可用 | 保留 UV | 重塑区域棋盘格/图案拉伸、接缝 |
| 重拓扑、需要原布局 | 按片区从原供体转移 UV | 最近面误投、内外层/手指/左右侧、镜像和岛边界 |
| 新布局/新部件 | 标缝、展开、纹素密度/留边，再绘制或烘焙 | 全部依赖 UV 的贴图重新核对 |

UV 是面角/loop 数据；空间顶点可对应多个 UV。不能用“每个空间顶点一个 UV”作为通用 Blender 数据模型。转移时核实版本中的面角映射选项；最近面插值只是候选。[Blender Data Transfer](https://docs.blender.org/manual/en/latest/modeling/modifiers/modify/data_transfer.html)

1. 保存原 UV 和采样对照；确认活动 UV 层、有意镜像重叠/平铺。
2. 分部件/层/侧限制供体与距离，近邻重叠面单独处理。同顶点数不是对应证据。
3. 使用带方向数字棋盘格环绕检查指蹼、腋窝、后跟、足弓、领口；统计退化 UV、翻转、越界、岛间距。故意镜像可以保留但需记录。
4. 按目标分辨率与 mip 留 padding，检查缩小贴图后的接缝。
5. 在导出 NIF 上重新检查 UV/纹理，源工程正常不证明拆点/切线正常。

audit_mesh.py 只查缺失/非有限/退化 UV 及散列，不检测所有重叠、拉伸、padding 或错误供体；需视觉或专用工具补证。

## 法线分层诊断

网格法线/硬边/自定义法线、切线空间法线贴图、反射遮罩/cubemap/shader 都可能影响色块。先中性无贴图材质查面向与曲率，再高光查连续性，最后恢复游戏材质。先排除重复面/穿插/几何折线，再考虑平滑法线；保留鞋底边或甲片棱等有意硬边。

## 高低模烘焙

1. 固定低模 UV、三角化和平滑边后再烘焙；改变对角线可能需要重烘焙。
2. 高低模处于同坐标系/姿态；分部件隔离射线，避免另一根手指或内层接收错误细节。
3. 明确 source/active target、目标图像、法线空间、cage/射线距离；局部测试再扩展，不给全身无限射线距离。[Blender Baking](https://docs.blender.org/manual/en/latest/render/cycles/baking.html)
4. 核实目标 shader 法线 G 方向、alpha 用途、DDS 压缩与色彩空间；用已知正确贴图对照，不一律翻 G/删 alpha。
5. 导出后在目标管线验证；Blender 光照只是近似。保存烘焙设置/高低模对应。重算网格法线不必重做 UV；重做 UV 后检查所有依赖 UV 的纹理。
