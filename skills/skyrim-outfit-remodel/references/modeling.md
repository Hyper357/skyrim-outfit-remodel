# 参考、形体、拓扑

## 统一参考

优先用户指定参考。补图时保持同一件装备/同一侧/比例/地面线/穿戴姿态，提供正、外侧、背、内侧与结构局部。图像生成器的线网是示意，不能当真实拓扑；视图冲突时指定主轮廓并说明取舍。

提示词模板：

> 同一件 [装备] 的建模参考板：[主视角] 与 [局部]，保持比例、部件位置和穿戴姿态一致。中性灰材质、清晰轮廓、控制透视，显示 [结构] 与接合边界；细小错落的受力褶皱，避免整齐横圈、夸张骨突、矛盾视图。线网仅作结构导引。

## 顺序与专项

总体比例/侧面剪影 → 截面/人体结构 → 部件接合 → 边流与密度 → 小褶皱/细节。灰模查体积，高光查曲率，多个方向环绕检查。保护已确认区域并记录快照，局部编辑边界渐变，避免密度或曲率突跳。Smooth 不用于抹掉骨点、足弓和已确认褶皱。

| 类型 | 造型重点 | 动态检查 |
|---|---|---|
| 鞋靴 | 先鞋身底边，再薄底和跟座。尖头有截面体积、前掌略抬、脚背坡连续；后跟圆润、跟座口收束流畅。底/跟可连续一体，也可按材质/变形需要拆分 | 足踝、脚趾、膝盖；细跟不被脚趾拉弯；保留原高跟抬升机制 |
| 手套/护臂 | 五指、指根蹼、指节、手腕与袖口；关节增环线 | 握拳、伸指、拇指对掌、腕屈伸 |
| 紧身衣物 | 胸腹/腋窝/胯/膝肘沿体表安排边流，按指定内层贴合 | 抬臂、肘屈、蹲伏、扭转 |
| 领口/头套 | 贴合与颈部跟随分开检查；头套确认面部形态需求 | 转头、低仰头、肩部移动；适用时面部测试 |
| 硬甲 | 刚性板和软连接分开；保持厚度与关节活动间隙 | 板不拉伸/塌陷，不刺入相邻板 |
| 裙摆/披风 | 保留骨链/物理层，确认内外表面，另读 physics.md | 行走、蹲伏、转向、静止恢复 |

四边面利于编辑但不是质量证明。优先规则截面和密度过渡，避免长瘦面和集中高价点；少量低变形区域三角面可接受。查重复面、零面积、松点、翻面、自交、意外孔洞；预期袖口/领口不自动封死。

UV/法线导出拆点正常，不能全部合并。新网格稳定后再处理数据；有高模时低模剪影仍应独立成立。
