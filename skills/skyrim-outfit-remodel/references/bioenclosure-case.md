# BioEnclosure / Wing：已做方法与证据边界

2026-10-13 整理。只公布自写方法和数值汇总，不分发原模组模型、贴图、工具二进制、个人路径或完整资源快照。用户对半透明版贴合给出积极反馈；该反馈不等于所有动作与物理已测试。

## 半透明 3BA 外壳

最终采用目标身体表面派生外壳，而非只让旧衣 Shrinkwrap。按原覆盖范围选 3BA 面、共享边中点细分，保存 donor 索引和重心系数；同一映射驱动外层基形、157 个身体 slider 和骨权重。按材质拆片时保存新旧点映射，高领另行恢复。Sheer 内层是实际 3BA 身体，最终没有整体内缩。

案例基础间隙 0.10 游戏单位；紧凹区域先按三角朝向局部减薄，再根据实际导出模型的有限 LBS 诊断修正 50 个点。0.10、减薄系数 .65、朝向余弦阈值 .08 与选面坐标都是此身体/网格的参数，不是通用衣物配方。

| 检查 | 实测范围 |
|---|---|
| 实际 preset 输出 | Creamy Curves，0/100 两端，4 个外壳 shape 输出 |
| 坐标与预期映射最大差 | 约 0.000197 游戏单位 |
| 外壳间隙 min / median / max | 约 0.003186 / 0.100000 / 0.100172 游戏单位 |
| top4 皮肤权重最大差 | 约 0.0002665 |
| 有限单骨 LBS 诊断 | 12 个记录姿态，无本诊断检测到的退化/反向面 |

LBS 绕实际绑定枢轴做有限角度旋转，属于几何诊断；不是 Skyrim 动画、CBPC 或 SMP 验收。领口延伸不纳入衣物到皮肤的距离统计。细节流程见 [fitted-clothing.md](fitted-clothing.md)。

## Wing 高叉与银色衬层接边

按真实 shape/组件识别管道，网格空间区域 rasterize 到 UV，把琥珀下缘改成 V 形并清除内腿旧橙条；上下衬层和导管统一银色柔性涂层。主要赛博文字在局部 albedo 与 normal 中处理，保留图集其余区域；黄铜参照实际手臂硬件材质。

上下裁切环分别 50/51 个几何位置。方向、周期相位与插入边中点的选择最小化位移，保留主环全部折点；另一片接到相同折线上。保留两个 UV shape，没有焊接成单一 mesh。附近 634 点以有限衰减协调位置、skin、法线和切线，40 组受影响 slider delta 更新主/FP OSD。

| 独立静态核验 | 结果 |
|---|---|
| 13 shapes 的顶点数、三角数组、UV | 保持 |
| 151 个非 UV/non-zap sliders 的边界位置 | 最大差约 1.94e-6 游戏单位 |
| 按骨名比较的边界权重 | 最大差 0.00024414，非逐字节相同 |
| 主/FP OSD 引用 | 1,516 条闭合，无越界 |
| PBR 材质 | Wing 7 套、28 张 BC7 DDS；原合并配置 40 项保留后共 47 项 |
| 运行资源与装备记录 | 原 mod 的 40 项资源胜出；仅 Wing 的 ARMA/ARMO 变更，其他 52 条记录保持 |

Wing 本轮没有代用户点击 BodySlide，没有游戏或动作验收。Blender 使用实际最终 NIF/DDS 静态预览；暂存运行时基形未套用户 preset。详见 [indexed-roundtrip.md](indexed-roundtrip.md) 与 [reference-colouring.md](reference-colouring.md)。

TruePBR 使用已核验脚本 NIF/DDS 路线，保留 `.tpbr` 可编辑项目；没有将其称为 Manager 原生 GUI 导出或全加载顺序 PGPatcher 已执行。工具兼容案例在配套 [TruePBR skill](../../skyrim-truepbr-workflow/SKILL.md)。
